# Security

## Reporting a vulnerability

Please do not open a public issue. Email **security@linearb.io** with a description, steps to reproduce, and the affected plugin and version.

LinearB's security practices: [linearb.io/security](https://linearb.io/security) · [Trust Center](https://trust.linearb.io)

## Supported versions

Fixes ship in the latest version of each plugin. With marketplace auto-update on, Claude Code picks them up automatically.

## Scope

Plugins in this repo run hooks on your machine and call the LinearB API with your `LINEARB_API_TOKEN`. Reports about token handling, hook behavior, or the data sent to LinearB are in scope.
